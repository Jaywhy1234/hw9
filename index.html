部署到 GitHub Pages 教學

只需將本網頁檔案上傳至 GitHub，即可免費擁有屬於自己的英語練習網站！

  1. 建立儲存庫 (Repository)：

    登入 GitHub，點擊右上角「+」選單選擇「New repository」，庫名填寫例如 english-pronunciation。

  2. 上傳 HTML 檔案：

    將這個 HTML 檔案命名為 index.html，上傳或 Commit 到該 repository 的主分支 (main)。

  3. 開啟 GitHub Pages 功能：

    進入 Repository 的 Settings ➔ 左側選單選 Pages ➔ 將 Source 設為 Deploy from a branch ➔ Branch 選擇 main 並儲存。

  4. 開始使用：

    等待 1-2 分鐘後，系統會生成網址：
    https://<your-username>.github.io/english-pronunciation/

注意事項： Chrome / Edge 等瀏覽器對 SpeechRecognition 的權限要求較高，必須在 HTTPS 環境（GitHub Pages 預設即為 HTTPS）或 localhost 下才能正常開啟麥克風！
